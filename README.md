# webllm-buffer-exp

Compare stock WebLLM with different WebGPU batching settings: 8, 16 or 32 dispatches per encoder, and 1 or 4 command buffers per submission.

Open the page and click **Run test**. Keep the tab visible. Allow about 10 minutes and a 200 MB download on first use.
